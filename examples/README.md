# 예제 코드

각 챕터 본문의 "참고 소스"에 적힌 파일들을 실제로 열어볼 수 있도록, 해당 챕터를 다룰 때 이 폴더에 원본을 복사해둡니다.

cikorea.net CI4 Playground 저장소 자체는 비공개이지만, 이 책에서 인용하는 파일만 여기 공개 사본으로 따로 보관합니다. 챕터 본문에 이미 핵심 코드가 전부 인용되어 있으므로, 이 폴더는 "직접 받아서 내 프로젝트에 넣어보고 싶을 때"를 위한 보조 자료입니다.

## 주의

- 여기 있는 코드는 원본 프로젝트의 네임스페이스/경로를 그대로 유지한 **발췌본**입니다. 그대로 실행되는 독립 앱이 아니라, 자신의 CI4 프로젝트에 가져다 붙이는 용도입니다. 각 폴더의 README를 참고하세요.
- 원본이 업데이트되어도 이 폴더는 수동으로만 동기화됩니다. 최신 상태가 아닐 수 있습니다.
