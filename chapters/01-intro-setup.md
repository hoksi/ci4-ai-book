# 1장. 왜 CI4 + AI인가, 개발 환경 세팅

## 왜 CodeIgniter4인가

Laravel, Symfony 같은 "풀 기능" 프레임워크와 비교하면 CodeIgniter4(CI4)는 의도적으로 가볍습니다. 매직(magic)이 적고, 설정보다 코드가 먼저 보이고, 러닝 커브가 완만합니다. "일단 돌아가는 걸 빨리 만들고 싶다"는 목표에 잘 맞습니다.

이 책은 CI4 문법을 하나씩 설명하는 레퍼런스가 아닙니다 — 그건 이미 [공식 유저가이드(한글 번역)](https://www.cikorea.net/docs/Codeigniter4)가 잘 하고 있습니다. 대신 **AI 기능이 들어간 실전 웹앱 하나를 처음부터 끝까지 만들면서**, CI4의 기본기가 실제로 어떻게 조합되는지 보여주는 데 집중합니다.

이 책 전체에서 공통으로 만들어갈 예제는 "**AI 게시판**"입니다 — 평범한 게시판에, 2부에서 AI 챗봇·스팸 필터·문서 검색봇을 하나씩 붙여나갑니다.

## 준비물

- PHP 8.1 이상, Composer
- SQLite (대부분의 PHP 설치에 기본 포함) — 별도 DB 서버 설치 없이 바로 시작할 수 있습니다

> **Windows를 쓰고 있다면** PHP/Composer를 Windows에 직접 설치하기보다 WSL(Linux) 환경을 먼저 만드는 걸 권장합니다. [부록 A. Windows + WSL 개발 환경 만들기](appendix-a-windows-wsl.md)를 먼저 보고, PHP와 Composer가 설치된 상태로 돌아오세요.
- [Groq](https://console.groq.com) 계정 — 무료 티어로 충분합니다

## 프로젝트 생성

```bash
composer create-project codeigniter4/appstarter ai-board
cd ai-board
```

CI4는 공식적으로 `public/`을 문서 루트로 두지만, 이 책의 13장(배포하기)에서 공유 호스팅에 올릴 때는 호스팅 쪽 제약 때문에 디렉터리 이름을 바꿔야 할 수도 있습니다. 지금은 기본 구조 그대로 진행합니다.

## .env 설정

CI4는 `env`라는 이름의 예시 파일을 제공합니다. 복사해서 `.env`로 만들고 필요한 값만 채웁니다.

```bash
cp env .env
```

```ini
#--------------------------------------------------------------------
# ENVIRONMENT
#--------------------------------------------------------------------
CI_ENVIRONMENT = development

#--------------------------------------------------------------------
# APP
#--------------------------------------------------------------------
app.baseURL = 'http://localhost:8080/'

#--------------------------------------------------------------------
# DATABASE (SQLite — 설치 불필요)
#--------------------------------------------------------------------
database.default.DBDriver = SQLite3
database.default.database = database.db

#--------------------------------------------------------------------
# AI (Groq)
#--------------------------------------------------------------------
GROQ_API_KEY = gsk_여기에_발급받은_키
```

`.env`는 절대 git에 커밋하지 마세요. API 키 같은 민감한 값이 들어가는 파일입니다. `appstarter`는 기본 `.gitignore`에 `.env`가 이미 포함되어 있지만, 한 번 더 확인하는 습관을 들이는 게 좋습니다.

## Groq API 키 발급

1. [console.groq.com](https://console.groq.com)에서 가입/로그인
2. 좌측 메뉴에서 **API Keys** → **Create API Key**
3. 생성된 키(`gsk_`로 시작)를 복사해서 위 `.env`의 `GROQ_API_KEY`에 붙여넣기

Groq 무료 티어는 모델별로 분당/일일 요청·토큰 제한이 있습니다. 정확한 수치는 콘솔의 **Settings → Limits**에서 확인하세요. 이 한도를 다루는 법은 11장에서 따로 설명합니다.

## 개발 서버 실행

```bash
php spark serve
```

브라우저에서 `http://localhost:8080`에 접속해 CI4 기본 환영 페이지가 뜨면 준비 완료입니다.

## 체크리스트

- [ ] `php -v`로 PHP 8.1 이상 확인
- [ ] `.env`의 `app.baseURL`이 실제 접속 주소와 일치하는가
- [ ] `.env`가 `.gitignore`에 포함되어 있는가
- [ ] Groq API 키가 `GROQ_API_KEY`에 등록되어 있는가
- [ ] `php spark serve`로 기본 페이지가 뜨는가
